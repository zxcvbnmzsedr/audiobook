在 Base 模型上训练 LoRA 适配器，创建自定义声音身份。上传数据集（包含 WAV 文件和 metadata.jsonl 的 ZIP），配置训练参数后即可运行。

训练配置

                    

                        

                            
                            
                        

                        

                            
                            
                        

                        

                            
                            
                        

                        

                            
                            
                        

                        

                            
                            
                        

                    

                    

                        

                            
                            
                        

                        

                            
                            
                        

                        

                            
                            
                        

                        

                            
                            
                        

                        

                            
                            
                        

                    


                    
                    

                        

                            这些设置如何影响 LoRA 声音质量
                            
                        

                        

                            

                                
LoRA 秩（Rank）

                                
控制适配器容量。较高秩（64+）能更强地捕捉声音身份，但可能削弱模型遵循 instruct/风格提示的能力，导致表达变平。较低秩（8-16）更保留表现力和提示词遵循能力，但声音细节较少。建议从 16-32 开始平衡。

                                
LoRA Alpha（缩放）

                                
LoRA 权重缩放系数。有效强度 = alpha / rank。相对 rank 更高的 alpha 会让适配器影响更大。常用起点是 alpha = 2 倍 rank。

                                
训练轮数

                                
完整遍历数据集的次数。太少会让声音身份无法收敛；太多会过拟合，产生卡顿、重复等瑕疵。20+ 条样本可从 15-30 轮尝试。

                                
学习率

                                
每步权重更新幅度。默认 5e-6 较保守。更高（1e-5）训练更快但更不稳定；更低（1e-6）适合较长训练。

                                
批量大小

                                
每步处理的样本数，受显存限制。24GB 显卡通常使用 batch 1 配合梯度累积。

                                
梯度累积步数

                                
先累积 N 步梯度再更新，用来模拟更大批量。有效批量 = batch_size x grad_accum。数值越高训练越平滑，但速度更慢。

                                
语言

                                
设置训练时使用的编解码器语言前缀 token。必须匹配训练音频语言；不支持的语言可尝试用 "english" 代替。

                            

                            

                            
训练数据建议：若想获得有表现力的声音，请包含多种情绪样本（开心、悲伤、愤怒、平静等）。只有中性样本的数据会训练出较平的声音，也更不容易响应 instruct 提示。
